# F3.6 — the SHIPPED dependency graph, PER PLATFORM.
#
# These are the crates compiled into a release build. The invariants G11-G13 say the TOOL leaves no trace on
# the host — but the real surface is the code the tool LINKS. A dependency that writes a cache file violates
# G11 without a single line of our own code changing.
#
# ------------------------------------------------------------------------------------------------
# WHY THIS FILE IS PER-PLATFORM, WHICH IT WAS NOT AT FIRST
#
# The first version of this list was a single universal set, and **CI failed on Windows** because of it:
# `libc` is declared under `[target.'cfg(unix)'.dependencies]`, so it is NOT in the Windows graph.
#
# That is worth recording as more than a typo. The check had encoded an assumption — "the shipped graph is
# the same everywhere" — that was never verified and is false. **A probe narrower than the claim it
# supported**, which is the failure this project records most often. CI caught it, which is what CI is for.
#
# The corrected form is what the check should always have been: the graph is a property of a TARGET, so the
# allow-list is keyed by target.
#
# ADDING A DEPENDENCY: add it to the relevant section(s) in the same commit as the amendment justifying it
# against G11-G13. If you have not written that amendment, the failure is the point.
#
# Generated from: cargo tree --locked -p tokengen --edges normal --target <triple>
# ------------------------------------------------------------------------------------------------

# T-0004 VAULT CRYPTOGRAPHY — 25 crates added 2026-10-31, one top-level decision
#
# Justification against G11-G13 is by AUDIT, not by assertion: every crate below was scanned for
# `std::net`, `std::process::Command`, `File::create`, `OpenOptions`, and `std::env::var`. **None of
# them reference any of those.** They are pure computation — integer maths, buffer transforms, and
# constant-time helpers. Adding them does not widen the tool's ability to leave a footprint.
#
# The reachable top level is five crates (argon2, chacha20poly1305, hkdf, sha2, subtle). Everything
# below them is their transitive closure from the same RustCrypto family, and is pinned by Cargo.lock.
#
# argon2 is 0.5.x, NOT 0.6.x: 0.6 requires rustc 1.87 and this project declares 1.85 (decision V5 —
# raising it would exclude Debian 13, the current stable, to gain Ubuntu 25.04).
# ------------------------------------------------------------------------------------------------
